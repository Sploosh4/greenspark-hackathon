# Local container source recipes

The ordinary stager packages selected Week Ahead/Season Ahead source, hashed PDF requirements, a reviewed DejaVu font and runtime launchers. It excludes live state, identities and raw upload packs. Use `python -B stage.py` for fresh ignored base contexts; it refuses to overwrite an existing context. The required font at `/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf` has SHA256 `b4c632e3cdf9acc7f28758fb5a323c8524d7fc6660d46904d9b6cbe2809c419c`, plus its distro copyright file.

Preview mode requires explicit `TEAM_CONNECT_UNAUTHENTICATED_DEMO=1`. Authenticated mode instead combines `compose.yaml` with `compose.authenticated.yaml`, separate pre-provisioned read-only identity volumes and no preview opt-in. `compose.authenticated-test.yaml` removes host ports. No account or store is created by staging.

Historical Q1 additionally uses `compose.replay.yaml` and `Q1_REPLAY_SNAPSHOT`, a read-only external JSON bind. Q3 history uses `compose.history.yaml` and `Q3_HISTORY_DIR` containing matching `metadata.json` and 96 separately verified PNG/gzip files. These external assets are not automatically copied into base contexts.

The accepted current Q1 image recipe is retained in `Dockerfile.q1-current`, `requirements-q1-current.txt`, `.dockerignore.current` and `compose.q1-current-isolated.yaml`. The standalone configuration requires existing private identity/state volumes, uses an external replay bind, enables current uploads only with authentication, and has no host ports, network or scheduler. Names/context paths are portable; the owner acceptance image was built from its separately fingerprinted context, not this checkout. No current image was rebuilt here.

Current inference needs the original frozen bundle and eight official Python 3.12 wheels. They remain outside Git. The generic stager copies the current inference tool text for source fingerprinting but does not assemble that model/wheel context. See [technical setup](../../docs/team-connect/SETUP.md), [model/data manifest](../../docs/team-connect/ASSET-MANIFEST.json) and [wheel manifest](../../docs/team-connect/Q1-CURRENT-WHEELS.json). An approved operator must supply and verify the complete current context before building; do not pass an incomplete base context to the current Dockerfile.

Run `python -B -m unittest discover -s tests -p 'test_*.py'` after source staging. These checks use temporary synthetic identities and stub serving without listeners. Compose checks render configuration only. Missing identities, ambiguous modes and implicit previews fail closed. Source checks do not grant public HTTPS, deployment or a new image result. Host/Origin/Secure-cookie work and activation remain the separate deployment phase.
